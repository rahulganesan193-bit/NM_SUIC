# Phase 1 - Empathy Map

## Primary User
ServiceNow Incident fulfiller / service desk user.

| Area | Observation |
|---|---|
| **Thinks** | “I need to enter the Incident quickly and correctly.” |
| **Sees** | Incident fields such as Category, Subcategory, Impact, Urgency, Priority and Assignment group. |
| **Does** | Creates, edits and submits Incident records. |
| **Feels** | Needs immediate feedback when a value is invalid or critical. |
| **Pain Points** | Invalid dependent values, missing mandatory information, accidental list edits. |
| **Needs** | Clear warnings, automatic field behavior and validation before save. |

## Expected User Experience

The system should guide the user while they enter data instead of waiting for server-side correction after submission.
